# Scrolling Text (Android Projekt)

Aplikacija **Scrollview_Android_Studio** je namenjena prikazu dolgih besedilnih člankov z uporabo drsnega pogleda (`ScrollView`) in postavitve v več stolpcih.

## Ključne značilnosti
- **Navpično drsenje (`ScrollView`):** Omogoča nemoteno pomikanje celotne vsebine (naslova, članka in gumba) od vrha do dna zaslona.
- **Postavitev v več stolpcih:** Uporaba vodoravnega `LinearLayout`-a za prikaz podnaslova v levem ožjem stolpcu in glavnega besedila v desnem širšem stolpcu.
- **Interaktivnost:** Gumb na dnu vsebine, ki ob kliku sproži prikaz obvestila (`Toast`).
- **Lokalizacija in viri:** Vsa besedila so ločeno shranjena v datoteki `strings.xml`.

## Uporabljene tehnologije
- **Jezik:** Java
- **Orodje:** Android Studio
- **Glavni gradniki:** `ScrollView`, `LinearLayout`, `TextView`, `Button`, `Toast`
